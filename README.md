# Komentář k zákonu č. 134/2013 Sb., o některých opatřeních ke zvýšení transparentnosti akciových společností a o změně dalších zákonů

Otevřený komentář k zákonu o zvýšení transparentnosti akciových společností — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; přeměna listinných akcií na majitele, postup a důsledky prodlení, výměna akcií, přechodná ustanovení a změny obchodního zákoníku, zákona o cenných papírech a zákona o podnikání na kapitálovém trhu.

Konsolidované znění: dokument e-Sbírky `SB-2013-00134_2013-06-30`.
